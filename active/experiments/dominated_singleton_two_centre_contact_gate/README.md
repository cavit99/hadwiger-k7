# Two-centre rooted-bag contact gate

This diagnostic asks whether two other independent degree-eight centres,
deleted before applying the complete seven-terminal kernel theorem, can
replace the single four-bag augmentation in the residual wheel/one-chord
cases.  Each centre is represented by the star added when it is absorbed
into one of the rooted bags it contacts.

The screen is a finite quotient test only.  A positive contact threshold
would still require an unbounded theorem that chooses one rooted kernel in
the common three-connected deletion so that the two literal centres meet
the required numbers of distinct bags.
