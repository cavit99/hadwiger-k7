# Complete seven-terminal kernel composition screen

This finite diagnostic retains the complete audited seven-terminal kernel
catalogue at the connected dominated degree-eight endpoint.  It tests the
three surviving labelled common-neighbour graphs against all 5,495 labelled
order-seven carriers and all 30,600 labelled order-eight owner families.

Run from the repository root:

```sh
uv run python active/experiments/dominated_singleton_complete_kernel_composition/verify.py
```

The order-seven quantifier is universal.  In the order-eight case a family
closes when at least one of its legal owner quotients produces a
`K_5`-minus minor together with the fixed common-neighbour graph.  These are
the exact quantifiers in the audited kernel theorem.
