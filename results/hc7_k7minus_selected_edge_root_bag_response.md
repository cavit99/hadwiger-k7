# Splitting a selected equality edge in a rooted `K_6` branch set

**Status:** written proof;
[separate internal audit GREEN](hc7_k7minus_selected_edge_root_bag_response_audit.md).
The final section records a route nonclosure, not a counterexample.  This
note does not prove the `K_7^-` six-colour conjecture or `HC_7`.

## 1. Setting

Let `G` satisfy

\[
 \chi(G)=7,\qquad
 \chi(J)\leq6\text{ for every proper minor }J,
 \qquad \kappa(G)\geq7,
 \qquad K_7^-\npreccurlyeq G.                       \tag{1.1}
\]

Fix an edge `e=up` and a proper six-colouring `phi` of `G-e` with

\[
                            \phi(u)=\phi(p).          \tag{1.2}
\]

Let

\[
                         (R,B_1,\ldots,B_5)           \tag{1.3}
\]

be a spanning `K_6`-minor model in `G/e`, with the contraction image of
`e` in `R`.  Lift the model to `G`, choose a spanning tree of the lifted
root bag containing `e`, and delete `e` from that tree.  Denote the two
resulting connected sets by `R_u,R_p`, according to the endpoint they
contain.

In the opposite-coordinate matching application, `phi` is the singleton
response in which `e` is monochromatic and the other deleted matching edge
is proper.  The common model in `G/e/f` lifts to a model of the form (1.3)
in `G/e`, so the theorem below applies to the already fixed common model.

## 2. The selected-edge split response

### Theorem 2.1

At least one of the following holds.

1. `G` contains a `K_7^-` minor.
2. One of `R_u,R_p`, say `Y`, has an actual boundary

   \[
                              S=N_G(Y),\qquad |S|\geq7,           \tag{2.1}
   \]

   with these additional properties:

   - `e` has one end in `Y` and the other in `S`;
   - some foreign branch set `B_j` lies in `V(G)-N_G[Y]`;
   - `phi|G-Y` is a proper six-colouring; and
   - the equality partition induced by `phi` on `S` does not extend
     through the intact graph `G[Y\cup S]`.

Thus the second outcome is an actual response-bearing separation which
retains the original selected edge and its original proper-minor
colouring.

#### Proof

Each foreign bag is adjacent to the union `R_u\cup R_p`, because it was
adjacent to `R` in the contracted model.  If at least four foreign bags
are adjacent to both split sets, then

\[
                         R_u,R_p,B_1,\ldots,B_5
\]

are seven pairwise disjoint connected branch sets with at most one
nonadjacent pair.  Indeed, the split sets are adjacent through `e`, the
foreign bags are pairwise adjacent, and the fifth foreign bag meets at
least one split set.  This is an explicit `K_7^-`-minor model.

Otherwise at most three foreign bags meet both split sets.  In particular,
one split set, say `Y`, is anticomplete to some foreign bag `B_j`.  Since
branch sets in a minor model are pairwise disjoint, `B_j` is disjoint from
`Y`; hence

\[
                         B_j\subseteq V(G)-N_G[Y].                 \tag{2.2}
\]

It follows that `N_G(Y)` is an actual boundary.  Seven-connectivity gives
`|N_G(Y)|>=7`.

The edge `e` joins the two split sets.  Its only endpoint in `Y` is
therefore deleted on restricting `phi` to `G-Y`.  Every other edge of `G`
is an edge of `G-e` and is proper under `phi`, so this restriction is a
proper six-colouring.

Suppose that a proper six-colouring of `G[Y\cup S]` induced the same
equality partition on `S`.  A permutation of its colour names would make
the two colourings agree on `S`; gluing them would give a proper
six-colouring of `G`, contrary to (1.1).  The intact side rejects the
partition, proving outcome 2. `\square`

### Corollary 2.2 (bounded unlabelled endpoint)

In outcome 2, either `7<=|S|<=9`, retaining all the labels in Theorem 2.1,
or the large actual-boundary singleton descent can be iterated to return an
actual response boundary of order seven, eight or nine.

The descended response is generated by a fresh edge deletion at a
low-degree singleton.  It need not retain `e`, the model labels, the
original shore, or the equality partition induced by `phi`.

#### Proof

If `|S|<=9`, keep `S`.  If `|S|>=10`, apply the audited large
actual-boundary singleton descent.  Each step strictly lowers the boundary
order and retains an actual response separation, so the process terminates
at order seven, eight or nine.  The construction of that descent uses a
fresh edge-deletion colouring, giving exactly the stated loss of labels.
`\square`

## 3. Audit of the existing exchange machinery

Theorem 2.1 is the strongest direct consequence of the existing machinery
for the all-lock root-bag split.

- The minimal contraction-bag normalization produces the same deficient
  split and an actual boundary of order at least seven.  Its detachable
  pieces carry model labels, but it gives no upper bound on the boundary.
- The two-mark and atomic two-pole split theorems likewise return an
  unbounded actual separator; they do not carry the selected colouring
  partition.  The proof above adds precisely that colouring trace.
- The colour-matched path exchange theorems require a previously fixed
  near-`K_7` model, protected branch sets and a path with prescribed first
  hits.  The all-lock paths supply colours, not those branch-set labels.
- The paired-source transfer theorem can return an exact order-seven
  labelled separation, but it assumes the special three-owner order-eight
  configuration and a five-target fan.  Neither hypothesis follows from
  the matching-square common model.
- First-hit rank-preserving transfer assumes an owner set of order at most
  one.  A lock path may traverse several foreign bags, so that hypothesis
  is also unavailable.
- The adjacent-pair palette linkage and double-critical rooted-fan
  alternatives live in `G-{u,p}` and do not align their branch sets with
  the independently chosen model in `G/e`.  They therefore do not improve
  (2.1).

None of these results yields a common boundary partition.  None bounds the
original labelled boundary by eight.  Corollary 2.2 bounds only a fresh
response by nine.

## 4. Exact route nonclosure

The all-lock hypothesis is not used in Theorem 2.1.  It cannot currently
sharpen the theorem because the five bichromatic lock paths need not be
internally disjoint and their palette labels do not identify the five
foreign branch sets.  In particular, several lock paths may cross
`N_G(Y)` at the same vertex, so they give neither five distinct boundary
vertices nor an upper bound on `|N_G(Y)|`.

The first unsupported inference is therefore

\[
 \begin{gathered}
   \text{five palette locks for the selected equality edge}\\
   +\ \text{the response-bearing split in Theorem 2.1}
 \end{gathered}
 \Longrightarrow
 \begin{gathered}
   |N_G(Y)|\leq8,\quad\text{or}\\
   \text{a partition common to both original shores.}
 \end{gathered}                                      \tag{4.1}
\]

A valid continuation must make the lock paths respect the foreign model
labels, or must show that the fresh order-nine endpoint in Corollary 2.2
re-enters the original matching row with its labels.  Applying another
unlabelled separator descent does not do either.
